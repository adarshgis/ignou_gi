# IGNOU Geoinformatics Hub

IGNOU Geoinformatics Hub is a community-driven repository that aims to organize and provide easy access to study resources for IGNOU Geoinformatics programmes, including PGCGI, PGDGI, and MSCGI.

## About

This repository serves as a central collection of academic resources to help students access programme information, course materials, and other useful references in a structured manner.

The project is intended to simplify resource discovery and encourage collaboration from the student community.

## Repository Contents

* Programme Guides
* Course Information
* Study Notes
* Previous Year Question Papers
* Assignments
* Practical Manuals
* Reference Materials
* Additional Learning Resources
